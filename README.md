# Vanilla RAG with Semantic Chunking

This repository contains an IPython Notebook (.ipynb) developed in Google Colab that implements a vanilla Retrieval-Augmented Generation (RAG) system with semantic chunking.

## Overview

The notebook demonstrates how to build a basic RAG system that retrieves relevant information from a knowledge base to augment the responses of a language model. Semantic chunking is used to improve the quality of retrieved information.

## Usage

To use this notebook:

1.  Open it in Google Colab.
2.  Follow the instructions within the notebook to set up the knowledge base and run the RAG system.

Feel free to modify and adapt this code for your own projects!
